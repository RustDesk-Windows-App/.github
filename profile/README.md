## 🖥️ What It Is
RustDesk for Windows is a free remote desktop app that connects you to another computer in seconds. Share a screen, take control, and move files back and forth, all through an encrypted session. Because RustDesk is open-source and can be self-hosted, you can run your own server and keep every connection private. It is a great fit for helping family with their PC, supporting coworkers, or reaching your own machine while away. Simple to start, powerful when you need it, this RustDesk download keeps remote access in your hands.

## ⭐ Key Features
> A free, open-source remote desktop that you can even host yourself.

- 🔐 **Encrypted sessions** — Control remote PCs over end-to-end encrypted connections.
- 📁 **File transfer** — Send files to and from the remote computer.
- 🏠 **Self-hosting** — Run your own relay and ID server for full control.
- 🌐 **Cross-platform** — Connect Windows with other supported systems.
- 🔑 **Unattended access** — Reach a device with a set password, no one needed on the other end.

## 👣 First Steps
1. Launch RustDesk on both computers.
2. Share the remote PC's ID and password.
3. Enter them on your PC to connect.
4. Control the screen and transfer files.
5. Set a permanent password for unattended access.

## 💬 Questions
**Is it free?**
Yes. RustDesk is a free, open-source remote desktop for Windows, available on GitHub.

**Can I install my own server?**
Yes. RustDesk supports self-hosting, including server deployments via Docker, so you can run your own relay and ID server.

**Which versions of Windows are supported?**
Modern 64-bit Windows, including Windows 10 and Windows 11. The latest stable release is recommended.
